# LiteWMS ТСД — запуск на телефоне через UserLAnd + Expo Go

Приложение на **React Native (Expo SDK 57)**. Разработка — в репозитории
`ahilespelid/litewms_tsd`, запуск — прямо на Android: dev-сервер Metro крутится
внутри **UserLAnd** (Linux на телефоне), а открываешь в **Expo Go (SDK 57)**.

> Почему так работает без QR и туннеля: UserLAnd (proot) не изолирует сеть —
> порт `8081`, поднятый в Linux-окружении, доступен другим приложениям телефона
> по адресу `127.0.0.1`. Поэтому Metro поднимаем в режиме `--localhost`, а в
> Expo Go вручную вводим `exp://127.0.0.1:8081`.

---

## 1. Разовая настройка UserLAnd (один раз)

Expo SDK 57 требует **Node 20+**. В UserLAnd ставим его через nvm (не бери
старый `apt`-ный nodejs — он слишком древний):

```bash
# обновить систему и поставить базовое
sudo apt update && sudo apt install -y git curl

# nvm + Node 20 LTS
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash
exec $SHELL          # перечитать профиль (или закрой/открой сессию)
nvm install 20
nvm use 20
node -v              # должно быть v20.x
```

Клонируем проект:

```bash
cd ~
git clone https://github.com/ahilespelid/litewms_tsd.git
cd litewms_tsd
npm install          # поставит зависимости (пару минут)
```

---

## 2. Команда запуска (каждый раз)

```bash
cd ~/litewms_tsd && npx expo start --localhost
```

Дальше на телефоне:

1. Открой **Expo Go**.
2. **Enter URL manually** (ввести адрес вручную).
3. Введи: `exp://127.0.0.1:8081`
4. Приложение соберётся и откроется. Правки в коде подхватываются на лету
   (Fast Refresh).

Остановить сервер — `Ctrl+C` в UserLAnd.

---

## 3. Если что-то не так

| Симптом | Что сделать |
|---|---|
| Expo Go: «No usable data» / не подключается | Проверь, что сервер реально слушает: в логе Metro должно быть `exp://127.0.0.1:8081`. Порт занят — закрой старый процесс или запусти с `--port 8082` и вводи его в Expo Go. |
| «Incompatible SDK version» | Проект на SDK 57; убедись, что Expo Go тоже SDK 57 (эта версия и стоит у тебя). |
| Долго висит на «Bundling» | Первая сборка на телефоне медленная — это норма. Дальше быстрее за счёт кэша. |
| Нехватка памяти при bundling | Закрой лишние приложения; при повторах помогает `--localhost` (без туннеля, меньше нагрузка). |
| Нужен доступ с другого устройства | Вместо `--localhost` — `npx expo start --tunnel` (нужен интернет, поставит `@expo/ngrok`). |

## 4. Что уже внутри («полотно»)

Файловая навигация **expo-router** — один файл в `app/` = один экран:

```
app/
  _layout.js        общий каркас: загрузка шрифтов Golos Text + Stack-навигация
  index.js          экран авторизации (в стиле litebox)
  home.js           рабочий стол — сетка модулей ТСД
  module/[key].js   универсальный экран операции: поле скана + накопитель
components/          Brand, PrimaryButton, Field, ModuleCard
data/modules.js     список модулей (Приёмка, Размещение, Отбор, ФБС …)
theme.js            цвета/шрифты/отступы, снятые с боевого litebox
```

Пока это **визуальный каркас**: навигация и внешний вид есть, реальных запросов
к бэкенду и работы с железным сканером нет (железный сканер и Bluetooth-печать
требуют собственной сборки — dev-build, а не Expo Go; это следующий этап).
